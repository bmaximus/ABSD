# Inbox — enrichment proposals from products

Products send their universal lessons here, verbatim, as `<product-slug>-YYYY-MM-DD.md` (format:
`absd/playbook/process/enrichment.md`). Proposals are applied by the ABSD-side procedure in that file; once applied
or rejected, the file stays as the record and its outcome is listed in `absd/CHANGELOG.md`. This folder never ships
to products.
